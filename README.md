The Moon finally answers back. After four billion years of wishes, howls, and 2 a.m. promises, it has one line for everyone staring up at it — and the answer is still no.

## Run it

```sh
python3 main.py
```

Writes the Moon's one-line answer to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
